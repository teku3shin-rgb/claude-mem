# 就活スケジュール帳

ES締切・説明会・Webテスト・面接の予定と、企業ごとの選考状況をまとめて管理する1ファイルのWebアプリです。

## 機能

- **予定**: 今日以降の予定を日付順に表示（「今日」「明日」「あとN日」のカウントダウン付き）。期限切れの未完了予定は先頭に表示
- **カレンダー**: 月表示。日付を押すとその日の予定を表示・追加
- **企業・選考状況**: 「気になる → エントリー済 → … → 内定」の段階ごとに企業を整理。段階はカードから直接変更可能
- **サマリー**: 今日の予定 / 7日以内の締切 / 期限切れ / 選考中の企業数 / 内定数
- 各予定から Google カレンダーへの登録リンク

## データの保存先

- claude.ai の Artifact として開いた場合: Artifact のデータベース（端末をまたいで同期）
- このファイルをブラウザで直接開いた場合: そのブラウザの localStorage（その端末のみ）
