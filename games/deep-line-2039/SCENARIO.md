# 深層線 DEEP LINE 2039 — シナリオ

## 世界

2019年の夏、東京の空が白く焼けた。人々はそれを「大閃光」と呼ぶ。
20年後の2039年、地上は灰と放射能に覆われ、変異した獣が街を歩いている。
生き残った人々は地下鉄の駅に逃れ、駅ごとに小さな共同体をつくって暮らしている。

- **月島駅**：有楽町線の東の果て。隅田川の下にある小さな駅。住人は約80人。
- **永田町駅**：いくつもの路線が交わる中央の駅。「評議会」が地下鉄網を取り仕切る。住人は約5000人。
- **赤環（せきかん）**：銀座一丁目を根城にする略奪者の集団。赤い布を巻いている。
- **ムクロ**：トンネルに棲む変異体。群れで動き、音と光に反応する。
- **ハグレ**：地上を群れでうろつく犬のような変異体。
- **ヌシ**：ムクロの巣に棲む大型個体。突進して壁にぶつかると動きが止まる。
- **モグリ**：トンネルや地上を行き来する駅の偵察者。
- **鳴子（なるこ）**：旧政府の音響兵器。ムクロが嫌う低い唸りを流し、群れを音から遠ざける。

## 物語の流れ

### 第一章「月島」
ハルはクロダに起こされ、駅長ミナミに呼ばれる。この三週間、ムクロの群れが日に日に増えていた。
シノが記録した謎の信号は、毎晩同じ時刻に流れ、発信源は永田町らしい。
ハルはテープを永田町の評議会へ届け、信号を止めるよう頼む役目を任される。
テープを受け取った直後、南のバリケードをムクロが越えてくる。駅の見張りと共に撃退したあと、ハルはクロダと北のゲートから旅立つ。

### 第二章「残響」
新富町へ向かうトンネル。保守室では負傷した旅人が医療キットを求めている。
二十年前から止まったままの列車を抜けた直後、天井が崩れてクロダと分断される。
ひとりで進むハルの前に「残響」が現れる。灯りが明滅し、あの日トンネルに閉じ込められた人々の影が立ち並び、存在しない列車の光が通り過ぎていく。

### 第三章「瘴気」
新富町駅は無人だった。割れたガス管から毒の霧が満ち、ガスマスクなしでは息ができない。
地上へのシャッターを開けるため発電機を動かすと、その音でムクロの巣が目を覚ます。
シャッターが開くまでの約50秒、群れと巨大な「ヌシ」を相手に持ちこたえる。

### 第四章「灰の空」
ハルは初めて空を見る。灰色で、重たく、どこまでも続く空。
放射能の満ちた銀座の街を、フィルターの残り時間と相談しながら北へ進む。
崩れた店の奥では、変異した母獣が仔を守っている。撃たずに通り過ぎることもできる。
途切れ途切れの無線で、クロダが生きていることを知る。

### 第五章「赤環」
銀座一丁目は略奪者・赤環の縄張り。電球を撃って闇をつくり、背後からナイフで静かに倒すこともできる。
焚き火のそばの兵の会話から、ハルは信号の正体が「鳴子」であることを知る。鳴子に追われたムクロは東へ、つまり月島へ流れていく。
檻に捕らえられた行商人を逃がすか。追い詰められて降伏した若い兵を撃つか、見逃すか。

### 第六章「永田町」
大理石の駅で、評議長サカキはテープを聞き、鳴子を流しているのは評議会だと認める。
「中央の五千人のために、外縁の八十人を差し出す」。サカキはハルに、永田町に残るか、黙って帰るかを迫る。

## 選択と結末

道徳的な行動は画面に表示されず、内部で数えられる（メトロシリーズの「隠しカルマ」と同じ考え方）。

| 行動 | 評価 |
| --- | --- |
| ユキに軍用弾を1発あげる | +1 |
| ソウタの話を最後まで聞く | +1 |
| 旅人に医療キットを渡す | +1 |
| 母獣と仔を撃たずに通り過ぎる | +1（撃つと −1） |
| 檻の行商人ヤマダを逃がす | +1 |
| 降伏した赤環の兵を見逃す | +1（撃つと −1） |

結末は3つ。

- **灰**：永田町に残る。鳴子は鳴り続け、その冬、月島からの無線は途絶える。
- **沈黙**：鳴子を止めるが、評価が4未満。ひとりで逃げ延びるが、クロダは帰らない。
- **夜明け**：鳴子を止め、評価が4以上。月島の仲間を連れたクロダが助けに現れる。二人は地上で、雲の切れ間から差す光を見る。
